# Bazion Web roadmap

The authoritative phase-by-phase implementation roadmap is maintained in [implementation-roadmap.md](implementation-roadmap.md).

The roadmap implements the advertised capabilities in products/catalog.json through reusable domain modules, then assembles them into the versioned solution manifests under solutions/.

The delivery order is:

1. Stabilize engineering, tenant recovery, durable notifications, permissions and audit.
2. Complete the platform control plane: tenant lifecycle, module registry, entitlements, branding and custom domains.
3. Build the shared design system, CMS, page builder and website templates.
4. Add forms, contacts, media, documents, search, SEO and localization.
5. Add client portals, booking, notifications, jobs and integrations.
6. Harden commerce, payments, inventory, promotions and fulfilment.
7. Operationalise hosting, deployments, backups, monitoring, security and care plans.
8. Assemble corporate, ecommerce, professional services, startup SaaS, church, school, NGO, clinic and ERP solution packs.
9. Add commercial sales/delivery workflows, enterprise features and permission-checked AI/MCP operations.

Do not treat this sequence as a commitment to build all modules at once. Each phase has explicit exit gates in the implementation roadmap.
